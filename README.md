# Direct

Public releases and issues for [Direct](https://www.cratis.io/direct/).

## Direct Agent Runner

Run Direct's agents on your own machine. Download the file for your system from the
[releases](https://github.com/Cratis/DirectPublic/releases), or on macOS and Linux install it with Homebrew:

```shell
brew tap cratis/cratis
brew install direct-runner
```

Then open <http://127.0.0.1:7190> to connect it to Direct. The full guide, including Windows and starting the runner at login, is at
[cratis.io/direct/runner](https://www.cratis.io/direct/runner/getting-started/).

Report problems with the runner or its documentation in this repository's issues.
